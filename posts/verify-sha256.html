How to Verify a Download with SHA-256

November 4, 2026

Downloading an operating system image is only half the job. Before you write it to a USB drive, you should confirm that the file is exactly what the project published, and that nothing got corrupted or swapped on the way. A SHA-256 checksum lets you do that in under a minute.

What a checksum does

A checksum is a short fingerprint calculated from a file's contents. If even one byte changes, the fingerprint changes completely. The project publishes the correct fingerprint, you calculate your own, and the two must match.

Step 1: Get the official hash

Copy the SHA-256 value from the project's own website, usually on the download page or in a file named SHA256SUMS. Use the project's HTTPS site, not the page or mirror you downloaded the image from. If both come from the same untrusted place, a matching hash proves nothing.

Step 2: Calculate the hash of your file

Windows (PowerShell)

Get-FileHash .\distro.iso -Algorithm SHA256

Windows (Command Prompt)

certutil -hashfile distro.iso SHA256

Linux

sha256sum distro.iso

macOS

shasum -a 256 distro.iso

Step 3: Compare

Every character must match. Letter case does not matter, but any other difference does. If the two values are different:

  • Delete the file and download it again.
  • Try a different official mirror.
  • If it still fails, do not use the image.

Going one step further: signatures

A checksum tells you the file was not damaged. A signature tells you who published it. Many projects, such as Debian and Ubuntu, sign their checksum files with GPG. If you want the extra assurance, follow the project's instructions to verify the signature on the checksum file as well.

Quick checklist

  • Download only from the official site or a mirror it links to.
  • Get the hash from the official site over HTTPS.
  • Calculate the hash yourself and compare every character.
  • Mismatch means start over. Never "just try it."

If a site offers an image with no checksum and no way to check who built it, treat it as untrusted.
